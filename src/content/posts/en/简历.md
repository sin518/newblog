AI Agent 智能助手后端 | NestJS · TypeScript · LangChain · Vercel AI SDK
▎
▎ 基于 NestJS 11 + LangChain Agent 构建的 AI 对话后端服务。集成 ReAct Agent 架构，注册联网搜索（Bocha API）和邮件发送两个自定义 Tool，实现 LLM 自主工具调用；通过 Vercel AI SDK + SSE 实现全链路流式响应；使用 Zod 定义 Tool 输入 Schema，结合 NestJS 依赖注入实现配置与业务逻辑解耦。采用 Jest + Supertest 进行单元测试，ESLint 9 Flat Config + Prettier 统一代码规范。
